## 📌 Project Overview

Organizations generate large amounts of knowledge across documents, systems, projects, departments, and business processes. Unfortunately, this knowledge is often siloed and difficult to navigate.

The Organizational Intelligence Engine converts organizational data into a searchable knowledge network that enables users to:

- Discover relationships between entities
- Explore organizational knowledge
- Analyze business connections
- Visualize enterprise networks
- Identify key knowledge hubs
- Generate organizational insights

The application demonstrates how Knowledge Graphs can be used to build organizational intelligence systems.

## 🚀 Features

### 📄 Document Repository
Browse organizational documents and metadata.

### 🏷 Entity Repository
Explore extracted entities such as:

- Technologies
- Applications
- Departments
- Projects
- Vendors
- KPIs
- Business Assets

### 🔗 Relationship Discovery
View relationships between entities.

Examples:

| Source | Relationship | Target |
|----------|-----------|----------|
